# F1 Driver Track Performance
This react application uses the [jolpi.ca](https://github.com/jolpica/jolpica-f1/tree/main) open F1 API to retrieve historical driver performance data per track over several years.
Qualifying and Race Results are compared against their team mate at the time, giving the user an idea of if a certain driver excels at a particular track.

# Instructions
Currently, the app doesn't have a docker file. After cloning the repository run:
```
npm install
```

Then to run:
```
npm start
```
